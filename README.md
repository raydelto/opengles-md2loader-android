# MD2 Loader for Android & iOS

This is a simple app for loading Quake 2 models (md2) into the Android & iOS platform with a Native C++ approach.

The android version uses a Kotlin layer to wire up high level details while the iOS version uses Swift with a thin Objective-C++ glue.
